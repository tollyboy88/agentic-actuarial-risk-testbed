# Scandinavian Actuarial Journal submission package

## Upload files

1. `final/01_manuscript_with_author_details.docx` — use for the journal's current single-anonymous workflow.
2. `final/03_author_details_title_page.docx` — separate author and declaration details.
3. `final/04_cover_letter.docx` — cover letter.
4. `final/05_supplementary_material.docx` — online supplement.
5. `final/06_tables.docx` — editable tables, one per page.
6. `final/figures/Figure_1.png` through `Figure_5.png` — separate 600-dpi figure files.

`final/02_anonymous_manuscript.docx` is supplied as a portable alternative if the submission workflow or a later journal requests double-anonymous review.

## Portal choices

- Article type: Original Article / Research Article.
- Publishing route: standard subscription publication; do not select paid Open Select unless you later want open access.
- Data statement: use the statement in the manuscript.
- Supplemental material: identify `05_supplementary_material.docx` as online supplemental material.
- Generative AI: copy the disclosure from the manuscript into any required portal field.

## Confirm before submission

- Confirm that “Independent Researcher, United Kingdom” is the desired affiliation.
- Confirm the no-funding and no-competing-interest declarations.
- Add an ORCID if available.
- Confirm email and any telephone number requested by the portal.
- Open the current journal instructions once more because publisher fees and portal fields can change.
